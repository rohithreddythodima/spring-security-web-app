# Secure Web Application

A Java web application built with Spring Boot and Spring Security to demonstrate authentication, authorization, and secure access to web pages.

## Features

- Secure login and logout
- Authentication for protected pages
- Public home page
- Custom login page
- Server-rendered pages using Thymeleaf
- Spring MVC configuration

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring MVC
- Thymeleaf
- Gradle

## Application Flow

1. Users open the public home page.
2. Protected pages require authentication.
3. Unauthenticated users are redirected to the login page.
4. Authenticated users can access protected content.
5. Users can log out securely.

## Getting Started

### Prerequisites

- Java JDK compatible with the project configuration
- Git

### Run the Application

On Windows, open a terminal in the project root and run:

```bash
.\gradlew.bat bootRun
```

Open your browser at:

http://localhost:8080

Use the sample credentials configured in the application's security configuration, if applicable.

### Run Tests

```bash
.\gradlew.bat test
```
